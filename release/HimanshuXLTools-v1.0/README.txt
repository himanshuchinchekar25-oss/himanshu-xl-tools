HIMANSHU XL TOOLS v1.0
======================

INSTALLATION

1. Close Microsoft Excel.
2. Right-click HimanshuXLTools-v1.0-Setup.exe.
3. Select Run as administrator.
4. Complete the installer.
5. Open Microsoft Excel.
6. Himanshu XL Tools should be available in Excel.

Internet connection is required for hosted add-in services
and license verification.

Version: 1.0.0.7

IMPORTANT:
Windows may show a security warning because this free release
installer is not digitally code-signed.

Only install this setup file when it was provided by the
official Himanshu XL Tools distributor.
