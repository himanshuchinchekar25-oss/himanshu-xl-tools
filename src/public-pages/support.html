Himanshu XL Tools - Support

Product: Himanshu XL Tools

Version: 1.0

Platform: Microsoft Excel

Getting help

When requesting support, include the Himanshu XL Tools version, Excel version and a description of the issue.

Licensing support

For activation, expiry, renewal or device-related issues, contact the Himanshu XL Tools support channel supplied with your license.

Technical support

For add-in startup or feature issues, include any error message shown by Excel.
